# 폴 동물병원 릴스

영상을 주면 Claude가 인스타 릴스로 편집해 주는 작업 공간입니다.
휴대폰 Claude 앱(Code 탭)에서 쓰며, 컴퓨터는 꺼져 있어도 됩니다.

## 쓰는 법
1. 촬영한 영상을 보낸다 (채팅에 첨부, 또는 구글 드라이브 `폴동물병원_릴스/01_원본_여기에올리기`)
2. "새 영상 올렸어. 코코 퇴원날이야" 처럼 한 줄 메모와 함께 말한다
3. 완성 영상 + 캡션 + 추천 음악을 받는다
4. 인스타 앱에서 음악만 얹고, 캡션을 붙여넣어 올린다

매주 월요일 아침에는 그 주 트렌드와 촬영 아이디어 3개가 드라이브 `02_트렌드노트`에 올라옵니다.

## 안에 있는 것
- `CLAUDE.md` — Claude가 따르는 작업 순서와 규칙
- `guide/style.md` — 폴 병원 릴스 스타일 (시리즈, 자막, 캡션, 해시태그, 촬영 요령)
- `tools/` — 편집 도구 (`sheet.py` 장면 보기, `make_reel.py` 릴스 만들기)
- `assets/fonts/` — 한글 폰트 프리텐다드 (SIL Open Font License)

영상·사진은 이 저장소에 올리지 않습니다 (공개 저장소).
